# PromoRadar AI v26 — Real Reward Calculator

База: v25 Multi-Exchange Live API.

Что добавлено:
- карточки теперь показывают мини-расчёт: `Доля / Награда` или `APR / Награда`;
- потенциал пересчитывается от выбранного депозита пользователя;
- сортировка `⏳ Осталось` идёт от большего срока к меньшему;
- `/api/live.js` обновлён до live v26 reward-calc;
- если биржа отдаёт APR/TVL/пул, клиент считает потенциал от этих данных;
- если публичных данных нет, карточка помечает расчёт как оценочный.

Важно: не все биржи публикуют стабильный публичный API для Launchpad/Launchpool. Следующий этап — точечно подключать официальные private/public endpoints или парсеры для каждой биржи и скрывать акции без подтверждения активности.
