# PromoRadar AI v41 Telegram Stars UI

База: v40 Favorites UX.

Изменения v41:
- Free/PRO режим.
- Free показывает одну биржу для демо, остальные карточки заблокированы.
- PRO экран с тарифами Telegram Stars: 1 день, 1 месяц, 6 месяцев, 1 год.
- Заготовка Telegram Mini App: Telegram WebApp ready/expand, отображение пользователя при запуске внутри Telegram.
- Кнопки тарифов подготовлены под подключение invoice Stars через Telegram-бота.

Важно: реальные платежи Stars требуют backend/бота Telegram. В этой версии добавлен интерфейс и клиентская подготовка.
